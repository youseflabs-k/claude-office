# Asset provenance

The 16 character GLB files and 36 furniture GLB files are taken from the Cozy Office regenerated asset pack supplied in this conversation. Their geometry is reused, not cut out from reference images. The character GLBs contain eight named node-transform animation clips, not skin/bone rigs. Scene layout, navigation, interaction engine, interface and React source are new for this app. No proprietary fonts, remote textures or AI-provider credentials are included.
